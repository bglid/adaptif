# Examples

Walkthrough examples on how to use the `adaptif` Rust crate in various situations. 

* [on-the-fly_adaptation.rs](https://github.com/bglid/adaptif/blob/main/examples/on-the-fly_adaptation.rs): Example of how to adapt and apply the filter on the fly to iteratively produce a cleaned signal. 
* [offline_adaptation.rs](https://github.com/bglid/adaptif/blob/main/examples/offline_adaptation.rs): Example of how to adapt a filter's weights and later apply the learned filter to produce a cleaned signal without updating the filter weights. 
* [custom_algorithm.rs](https://github.com/bglid/adaptif/blob/main/examples/custom_algorithm.rs): Example of how to implement your own custom algorithm from scratch using the `adaptif` filter engine.
