# Integration Tests

This directory contains `adaptif` API integration test suites for the Python package & Rust crate. It also contains pinned .wav files in `fixtures`, which are used in the integration tests. 

> [!IMPORTANT]
>The integration tests check for correctness of API behaviour and are not intended to be a guide for filter parameter choice. 

- - - 

To run the integration tests, we recommend using the `test-all` command in the `Makefile`, as documented in [CONTRIBUTING.md](https://github.com/bglid/adaptif/blob/main/CONTRIBUTING.md).
